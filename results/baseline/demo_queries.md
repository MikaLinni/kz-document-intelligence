## Живой показ

Подготовьте [локальный корпус](../../data/README.md#local-layout) и [веса](../../models/README.md#local-setup). Из корня проекта запустите двуязычный сеанс заранее. Дождитесь приглашения `>`. Построение плотного индекса выполняется при старте, после чего следующие вопросы используют подготовленные эмбеддинги из памяти процесса.

```bash
python scripts/demo_search.py --interactive
```

Вставьте сначала казахский, затем русский запрос про статью 22. Сравните позиции и покажите, что обе языковые версии ведут к той же статье. Для второго примера используйте вопросы про статью 34. Пустая строка завершает сеанс.

Для одного запроса или сравнения методов запустите конкретную команду.

```bash
python scripts/demo_search.py "Жер учаскесіне меншік құқығы қандай жағдайларда туындайды?"
python scripts/demo_search.py --method bm25 "Кто имеет право постоянного землепользования?"
python scripts/demo_search.py --method lora --lang kk "Тұрақты жер пайдалану құқығы кімдерге беріледі?"
```

Метод по умолчанию — `hybrid`. Если язык короткого вопроса определяется неоднозначно, укажите `--lang ru` или `--lang kk`. Балл зависит от метода и служит для сортировки результатов одного запроса. При отсутствии номера статьи или заголовка в метаданных выводится «—». Демо читает фиксированный корпус и локальные веса.
