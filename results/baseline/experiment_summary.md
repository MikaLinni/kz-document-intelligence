# Поиск по законодательству Казахстана

Задача проекта — найти фрагменты правовых документов, отвечающие на вопрос на русском или казахском языке. Бейзлайн сравнивает пять методов поиска. Каждый метод возвращает ранжированный список чанков из одной и той же коллекции.

## Корпус и эталон

Из 20 000 двуязычных записей исходного корпуса получено 305 375 чанков. Для эксперимента взяли 3 009 чанков семи документов, соответствие которых QA-источникам было проверено. Для каждого запроса поиск шёл по всем чанкам его языка в этой коллекции.

QA-набор изначально связывал вопросы с длинными контекстами, в которых могли быть сразу несколько статей. При переносе разметки на короткие чанки вопрос об одной статье иногда получал ID фрагмента из соседней. При исправлении разметки сначала отбирались кандидаты из нужного документа и языка, затем искалось точное совпадение по номеру статьи. Сходство с ответом, исходным контекстом и вопросом помогало выбрать конкретный чанк внутри статьи. В clean-разбиения вошли только строки с точным совпадением статьи и достаточными оценками сходства.

| Обучающие записи с тремя негативами | 1 086 | 919 | 167 |

## Методы и выбор модели

- **BM25** ранжирует чанки по словам запроса, учитывая частотность слов и длину чанка.
- **BGE-M3 zero-shot** кодирует запрос и чанк предобученной моделью. Результаты упорядочиваются по скалярному произведению нормализованных эмбеддингов CLS.
- **BGE-M3 LoRA** добавляет обучаемые адаптеры к BGE-M3. Контрастивная функция потерь повышает оценку эталонного чанка относительно трёх трудных негативов.
- **BM25 + zero-shot RRF** и **BM25 + LoRA RRF** суммируют вклады позиций из лексического и плотного рейтингов. Для обоих вариантов (K=60).

Эпоха 0 — исходная BGE-M3. Основной критерий выбора — Recall@10 на DEV. Эпоха 2 подняла его с 0,9754 до 0,9918, с 119 до 121 попадания из 122. Эпохи 3 и 4 повторили 0,9918. При равенстве сохранялась более ранняя эпоха, а после двух эпох подряд без улучшения обучение остановилось.

Финальную оценку на TEST провели однократно после фиксации чекпойнта. Это сохраняет независимую оценку качества этой конфигурации от решений, принятых при обучении и выборе эпохи.

## Итог на TEST

| Метод | Recall@5 | Recall@10 | MRR@10 | nDCG@10 |
|---|---:|---:|---:|---:|
| BM25 | 0,9104 | 0,9403 | 0,8381 | 0,8631 |
| BGE-M3 zero-shot | 0,9216 | 0,9403 | 0,8036 | 0,8376 |
| BGE-M3 LoRA | 0,9216 | 0,9590 | 0,8111 | 0,8474 |
| BM25 + zero-shot RRF | 0,9328 | 0,9552 | 0,8578 | 0,8820 |
| **BM25 + LoRA RRF** | **0,9403** | **0,9627** | **0,8624** | **0,8873** |

LoRA добавила пять попаданий в топ‑10 относительно zero-shot, с 252 до 257 из 268. Все пять пришлись на RU. У обеих плотных моделей результат KK составил 24 из 24, при этом размер подвыборки KK ограничивает выводы. Гибрид с LoRA дал 258 попаданий из 268 и лидировал по всем четырём общим метрикам. Эти результаты относятся к фиксированному корпусу семи документов и отфильтрованному QA-бенчмарку.
